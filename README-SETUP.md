
# DroneWatch — настройка сборки

## Назначение

Конфигурация проекта XcodeGen и автоматической сборки
приложения DroneWatch для iOS Simulator.

## Установка

1. Добавить project.yml в корень репозитория.
2. Создать каталог .github/workflows.
3. Добавить файл ios-build.yml в этот каталог.
4. Убедиться, что Swift-файлы находятся в корне репозитория.
5. Открыть вкладку Actions в GitHub.
6. Проверить запуск workflow iOS Build.

## Что проверяется

- Генерация проекта DroneWatch.xcodeproj.
- Компиляция приложения для iOS Simulator.
- Сохранение журнала сборки в артефактах GitHub Actions.

## Ограничения

- Успешная сборка симулятора не означает, что приложение установлено
  на физический iPhone.
- Для установки на iPhone потребуется подходящая подпись приложения.
- Официальные источники данных о воздушной обстановке пока не подключены.
- Экран радара не выполняет реальное обнаружение БПЛА.
- При ошибке сборки следует скачать артефакт xcodebuild-log
  и изучить первую ошибку компилятора.
